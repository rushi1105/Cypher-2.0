# Local model artifacts

These files are legacy inference artifacts used by `server/ml_predictor.py` on `/stream/enriched` and `/stream/windows`:

- `threat_classifier.pkl` — scikit-learn `RandomForestClassifier`
- `anomaly_detector.pkl` — scikit-learn `IsolationForest`

The newer CIC-IDS2017 flow models are loaded from `ml/artifacts/` by `server/flow_predictor.py` and served on `/stream/flows`:

- `binary_threat_classifier.joblib`
- `multiclass_attack_classifier.joblib`
- `flow_anomaly_detector.joblib`

Those artifacts are ignored by Git and are generated by `ml/train.py`.

Both models expect the 11-feature order defined in `server/ml_predictor.py`:

```text
packet_count, avg_packet_size, tcp_count, udp_count, unique_ips,
syn_count, tcp_ratio, syn_ratio, packet_size_std,
avg_interarrival_time, unique_ports
```

## Provenance

The original training dataset and training script are **not in this repository**. The models were created with scikit-learn 1.8.0 and are currently used for the integration demo only. Do not claim they were trained on self-captured traffic or CIC-IDS2017 until a reproducible training pipeline and evaluation report are added.

The planned replacement is documented in `ROADMAP.md` under M3: a reproducible training/evaluation pipeline with a dataset manifest, model card, and measured metrics.

## Reproducibility

Pin scikit-learn to `1.8.0` (see `server/requirements.txt`) to avoid unpickling version warnings. Retraining will produce new artifacts and should update this README with the exact command, dataset version, and metrics.
